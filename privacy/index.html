Overview

Genius CFO provides AI-powered accounting and CFO intelligence. We process data via secure integrations and do not store financial data directly.

Data collection

  • Personal info: name, email, phone
  • Business info via integrations (read-only where applicable)
  • User uploads (documents, invoices)
  • Usage, cookies, device data

Use of data

  • Provide and improve services
  • Generate insights
  • Customer support and communication
  • Compliance and security

Payments

We use Stripe, Razorpay, and PayPal. Payment data is processed by these providers and not stored by us.

Data sharing

  • Service providers (cloud, analytics)
  • Legal compliance
  • No sale of user data

Security

  • Encryption in transit
  • Access controls
  • No storage of financial data

User rights

  • Access, correction, deletion
  • Opt-out of marketing

Contact

For any privacy question or request, write to marketing@geniuscfo.ai.
